Image tags and changelog

Every release is published as a container image on ghcr.io/piyushdoorwar/yamlet. Use latest to stay current, or pin a version tag for a reproducible setup.

Run the latest image

Start it from your workspace folder, then open http://localhost:7878.

$ docker run -d --name yamlet -p 127.0.0.1:7878:7878 -v "$PWD:/workspace" -v yamlet-data:/data ghcr.io/piyushdoorwar/yamlet:latest

Update an existing container

Pull the new image, remove the old container and run the command again. Your YAML stays in your folder, and the yamlet-data volume keeps the Chrome extension paired.

$ docker pull ghcr.io/piyushdoorwar/yamlet:latest
$ docker rm -f yamlet
$ docker run -d --name yamlet -p 127.0.0.1:7878:7878 -v "$PWD:/workspace" -v yamlet-data:/data ghcr.io/piyushdoorwar/yamlet:latest
