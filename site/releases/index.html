Linux (Debian / Ubuntu) – .deb

Download the .deb from the Versions tab, then install it:

sudo apt install ~/Downloads/yamlet_*_amd64.deb

The build is self-contained — no separate .NET runtime is required.

Windows – .exe installer

Download the .exe installer from the Versions tab and run it. Self-contained; no extra runtime needed.

Windows – .msix package

Prefer MSIX? Download the .msix from the Versions tab. It ships unsigned, so install it with a trusted certificate or via Add-AppxPackage in a developer environment.
