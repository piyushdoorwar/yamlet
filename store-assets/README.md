# Chrome Web Store materials

The extension ZIP is generated by `npm run package:extension` and is written to `dist/`. These listing files are separate from the ZIP.

| Asset | Size | Purpose |
|---|---:|---|
| `extension/icons/icon128.png` | 128 × 128 | Required extension icon |
| `1-connect-1280x800.png` | 1280 × 800 | Pairing screenshot |
| `2-approve-1280x800.png` | 1280 × 800 | Site approval screenshot |
| `3-synced-1280x800.png` | 1280 × 800 | Connected screenshot |
| `promo-small-440x280.png` | 440 × 280 | Required promotional tile |
| `promo-marquee-1400x560.png` | 1400 × 560 | Optional promotional tile |

The screenshots render the real popup HTML and CSS with sample local state. Regenerate them after popup changes with `python3 store-assets/render.py` (requires Google Chrome, Pillow, and CairoSVG). Review the screenshots against a real installed extension before submitting.

`listing.txt` contains copy for the Store Listing, Privacy, and Test instructions tabs. Update it after local testing so every claim matches the released behavior. The public policy is at `site/policy/index.html`; deploy that page and verify its URL before submission. The developer account email must be verified in the Chrome Web Store dashboard.

The Chrome Web Store's current user-data policy requires secure handling and transmission of authentication cookies. This local test build encrypts cookie snapshots with AES-GCM before sending them over loopback HTTP. Confirm that arrangement is accepted under the policy, or move the bridge to an approved secure transport, before public submission.
