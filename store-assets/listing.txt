CHROME WEB STORE DRAFT — Yamlet Interceptor

Name: Yamlet Interceptor
Short description:
Sync cookies from websites you approve into the Yamlet API client running on your computer.

Detailed description:
Yamlet Interceptor connects Chrome's cookies to your local Yamlet workspace. Pair it with the Yamlet app, approve individual websites, and Yamlet can use those cookies when you send matching API requests.

How it works:
1. Run Yamlet locally and open its Cookies dialog.
2. Generate a one-time pairing code and enter it in this extension's popup.
3. Open a website and choose Allow & sync this site.
4. The extension refreshes approved sites while Chrome is running. You can also sync manually.

You control which sites the extension can read. It can include sign-in and HttpOnly cookies, so approve only sites you want to use in Yamlet. The extension does not read page text, capture requests, collect browsing history, or send cookies to a Yamlet cloud service. The Yamlet app runs on your own computer.

Approved sites and the pairing credential are stored locally in Chrome. Cookie values are read from Chrome when needed, encrypted before they are sent to the local Yamlet app, and held in the app's memory. Partitioned and incognito cookies are excluded in this release.

Privacy dashboard draft:
Single purpose: Sync cookies for user-approved sites into a user-run, local Yamlet workspace for API requests.
Data handled: authentication information (cookies, potentially including session tokens) and website domain names chosen by the user.
Use: attach matching cookies to requests sent in Yamlet. No advertising, telemetry, sale, or developer-hosted collection.
Transfer: Chrome extension to the user's own local Yamlet app. Cookie snapshots are encrypted with AES-GCM before transfer.
Storage: approved domains and pairing credential in chrome.storage.local; cookie values in Yamlet server memory; server pairing credential in a private local data volume.
Permissions:
- cookies: read cookies for sites explicitly approved by the user.
- activeTab: identify the current site when the user opens the popup.
- storage: retain approved sites and the pairing credential in this browser.
- alarms: periodically refresh approved sites after a server restart or missed cookie event.
- http://localhost and http://127.0.0.1 host access: connect to Yamlet running on this computer.
- optional website host access: request permission for one chosen website at a time.

Reviewer instructions draft:
Run the Yamlet container or local server at http://localhost:7878 as described in the repository README. In Yamlet, open Cookies and select Pair extension. Paste the code into the extension popup. Open a normal website tab with cookies, grant access in the popup, and refresh Yamlet's Cookies dialog. For a self-contained test, a local website that sets a sample cookie can be used. The extension requires a local Yamlet instance and does not connect to a developer-operated service.
